# Welcome

This is a sample page managed via **Content Files** in the CMS module.

## Why File-Based Content?

Content stored in `.md` files is:

- **Shared across deployments** — same content on every domain/subdomain
- **Version controlled** — tracked in Git alongside your code
- **Database independent** — no need to sync content between databases

## How to Use

1. Navigate to **CMS → Content Files** in the admin panel
2. Select a folder (Pages, Blogs, or Custom)
3. Click **New File** to create content, or **Edit** to modify existing files
4. Use Markdown syntax for formatting
5. Changes are saved to the file system and deployed with your code

---

> **Tip:** Use the live preview panel on the right side of the editor to see how your content will look.
